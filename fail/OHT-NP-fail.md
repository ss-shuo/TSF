# OHT-NP 失败复盘：余量归一化传输没有通过核心创新归因门

## 摘要

OHT-NP（Occupancy Headroom Transport Neural Process）尝试改进有容量上界的充电站占用概率预测。它的核心假设是：历史净变化不应直接平移到当前状态，而应先按当时的空闲量或占用量归一化，再作用于当前对应余量。这样理论上可以更合理地处理接近空站或满站时的边界效应。

小范围实验显示，OHT 相对原始 CAMP 概率模型有明显改善，并且在公平匹配门控后，相对普通增量平移的六个预测跨度点估计全部为正向。但是，OHT 相对最强匹配对照 ordinary shift 的提升很小，按站点 bootstrap 得到的所有 95% 置信区间均包含 0。因此，实验不能证明收益来自“余量归一化”这一核心操作，而不是来自更一般的历史增量传输。

这次失败属于**创新归因失败**，不是代码运行失败，也不是方法在所有场景下完全无效。OHT 可以保留为工程候选，但不应作为已经获得证据支持的核心创新继续扩展。

## 1. 要解决的问题

任务是预测未来 1–6 小时的整数占用量概率分布。每个站点有固定容量，预测分布的支持为 `0, 1, ..., C`。目标场景是未见站点上的少样本预测：模型可以使用目标站点过去 168 小时的合法观测，但不能使用查询时刻之后的数据。

基础模型 CAMP-NP 输出 Beta-Binomial 概率质量函数。OHT-NP 不替换基础模型，而是从支持窗中提取同跨度历史端点对，构造一个传输分布，再通过标量门控与基础分布混合。

## 2. 核心创新是什么

设站点容量为 `C`，历史端点占用量为 `y_s` 和 `y_e`，当前占用量为 `x`。

普通增量平移直接复用历史净变化：

```text
x_shift = clip(x + y_e - y_s, 0, C)
```

OHT 将上行和下行变化分别按历史余量归一化：

```text
若 y_e > y_s：
x_oht = x + (C - x) * (y_e - y_s) / (C - y_s)

若 y_e < y_s：
x_oht = x - x * (y_s - y_e) / y_s

若 y_e = y_s：
x_oht = x
```

直观上：

- 上行变化消耗空闲接口，因此按历史空闲量归一化，再乘到当前空闲量上；
- 下行变化释放占用接口，因此按历史占用量归一化，再乘到当前占用量上；
- 输出始终截断在 `[0, C]`；
- 当 `C=1` 时，OHT 与普通平移在可观测离散状态上没有可区分的几何作用，这是结构性负对照。

多个历史端点对经过相同的查询相关权重聚合，形成传输 PMF。最终预测为：

```text
p_final = (1 - eta) * p_base + eta * p_transport
```

其中 `eta` 只能在 source_train 数据上学习，不能读取 validation 或 blind test 标签。

真正需要验证的创新命题不是“传输分布优于基础模型”，而是：

> 在相同历史端点、相同权重、相同参数预算和相同训练信息下，余量归一化传输稳定优于普通增量平移。

## 3. 验证设计

实验使用 UrbanEV 小范围协议：

- 每个情节使用 168 小时支持窗；
- 完整评价 `H=1,2,3,4,5,6`；
- 664 个 validation 情节；
- 3,584 个可评分事件；
- 每个跨度覆盖约 302–303 个站点；
- 两个独立随机 seed；
- 基础模型采用小预算训练，每个 seed 为 3 epoch、每个 epoch 8 steps；
- OHT 和 ordinary shift 的标量门控均只在 source_train 上优化 80 steps；
- validation 只用于冻结后的比较；
- blind truth 始终保持封存。

主指标为离散 CRPS（dCRPS，越低越好）。主要创新归因比较为：

```text
Delta = dCRPS(OHT) - dCRPS(ordinary shift)
```

`Delta < 0` 表示 OHT 更好。除总体均值外，还按站点进行配对 bootstrap，避免把同一站点的大量相关事件误当成独立样本。

## 4. 验证过程暴露出的关键问题

### 4.1 初始正向结果只覆盖了部分跨度

最初的无训练几何验证和早期门控实验主要关注 `H={1,3,6}`。这些跨度出现了方向稳定的改善，但完整扩展到 `H=1–6` 后，使用共享 OHT 门控的比较在 `H=2` 和 `H=4` 出现损伤。

这说明早期结果存在明显的跨度选择风险。即使被选跨度不是事后挑选，只报告稀疏跨度也可能隐藏相邻跨度的失败模式。机制创新的首次有效性门应直接覆盖完整主跨度，而不是等出现正向结果后再补齐。

### 4.2 ordinary shift 曾被迫共用按 OHT 学到的门控

早期三方比较中，OHT 和 ordinary shift 共用了按 OHT 几何在 source_train 上学到的 `eta`。虽然两者的信息和传输权重相同，但这个比较仍不完全公平：适合 OHT 的混合强度不一定适合 ordinary shift。

这会把“几何差异”和“超参数适配差异”混在一起。修正方法是让两种几何在完全相同预算下分别学习自己的门控：

| seed | OHT eta | ordinary-shift eta |
|---:|---:|---:|
| 202601 | 0.768251 | 0.758170 |
| 202602 | 0.737135 | 0.720229 |

两种方法学到的门控接近但并不相同。这个问题最终被修复，但它说明强对照必须从第一次核心实验开始就拥有独立且等预算的调参机会。

### 4.3 相对弱基础模型的巨大收益掩盖了核心增量很小

匹配门控后的两 seed 事件平均 dCRPS 为：

| H | CAMP base | ordinary shift | OHT | OHT - shift |
|---:|---:|---:|---:|---:|
| 1 | 1.040409 | 0.551995 | 0.541918 | -0.010077 |
| 2 | 0.909246 | 0.444872 | 0.443890 | -0.000982 |
| 3 | 0.910530 | 0.447809 | 0.442054 | -0.005756 |
| 4 | 0.953318 | 0.495592 | 0.495011 | -0.000581 |
| 5 | 0.984487 | 0.568352 | 0.561524 | -0.006828 |
| 6 | 0.977344 | 0.607049 | 0.595810 | -0.011239 |

OHT 相对 CAMP base 的改善很大，但 ordinary shift 也获得了绝大部分改善。余量归一化带来的额外差异比通用传输收益小一到两个数量级。

如果只把 OHT 与 CAMP base 比较，很容易得出“创新非常有效”的错误结论。实际上，这只能证明“从支持窗传输历史变化有用”，不能证明“按余量归一化是必要的新机制”。创新必须与最接近、最强且信息匹配的替代解释比较。

### 4.4 点估计一致不等于证据充分

公平匹配后，六个跨度的事件平均点估计都偏向 OHT，两个 seed 的方向也一致。OHT 优于 ordinary shift 的站点—跨度单元比例为 `78.61%`。这些结果说明 OHT 仍有方向性信号。

但是，2,000 次配对站点 bootstrap 得到：

| H | 站点宏平均 OHT - shift | 95% CI |
|---:|---:|---:|
| 1 | -0.009806 | [-0.028911, 0.004374] |
| 2 | -0.000940 | [-0.010204, 0.008136] |
| 3 | -0.006162 | [-0.017888, 0.004865] |
| 4 | -0.001091 | [-0.010885, 0.010308] |
| 5 | -0.007121 | [-0.017247, 0.003490] |
| 6 | -0.011686 | [-0.025439, 0.001232] |
| all | -0.006136 | [-0.017104, 0.004300] |

所有区间都包含 0，预设的核心创新归因门没有通过。

这里的站点宏平均点估计与上一表的事件平均差值略有不同，这是聚合口径不同造成的：事件平均让事件较多的站点权重更高；bootstrap 先在站点内平均，再让每个站点获得相同权重。对于跨站泛化任务，后者是更合适的推断单位。

### 4.5 站点和容量异质性不可忽略

OHT 的作用依赖容量和当前边界状态。容量为 1 时，它与普通平移结构上等价；低容量站点提供的可区分形状空间也很有限。部分中高容量站点可能受益，但站点间效应差异较大，最终使总体置信区间跨 0。

因此，报告总体事件均值不足以支持机制结论。必须同时检查：

- 站点宏平均；
- 站点受益比例；
- 容量分层；
- 边界状态分层；
- 以站点为重采样单位的置信区间；
- `C=1` 结构负对照。

### 4.6 小模型 validation 不能升级为正式结论

当前证据来自两个 seed 的小预算模型和非盲 validation。它适合做候选筛选和停止决策，不适合宣称正式泛化提升。增加更多正式训练可能缩小不确定性，也可能改变基础分布质量，但在核心归因门尚未通过时直接扩大训练矩阵，会把大量计算投入到一个尚未成立的机制上。

## 5. 最终失败原因

OHT-NP 没有作为核心创新继续推进，主要原因如下：

1. **相对最强匹配对照的增益过小。** 大部分收益来自通用历史变化传输，而不是余量归一化。
2. **统计不确定性没有排除零效应。** 六个跨度和总体的站点 bootstrap 95% 区间均包含 0。
3. **站点异质性较强。** 事件平均和受益比例看起来积极，但不足以形成稳定的跨站机制证据。
4. **早期实验范围不完整。** 只看 `H={1,3,6}` 曾产生过于乐观的印象，补齐跨度后暴露了 `H=2,4` 的脆弱性。
5. **初始强对照调参不完全公平。** ordinary shift 曾共用 OHT 的门控，导致早期归因存在可质疑之处。
6. **基础对照太容易被击败。** 相对 CAMP base 的大幅提升不能替代与 ordinary shift 的核心机制比较。
7. **证据阶段有限。** 两 seed、小训练预算、非盲 validation 只能支持筛选，不能支撑正式创新声明。

## 6. 哪些部分没有失败

为了避免把“创新归因失败”误写成“所有工作无效”，需要保留以下事实：

- 数据协议、时间截断和盲测封存没有发现泄漏；
- PMF 支持、非负性、归一化和事件三方配对均通过独立检查；
- source-only 门控训练能够稳定运行；
- OHT 相对 CAMP base 有稳定改善；
- 公平匹配后六个跨度的点估计均偏向 OHT；
- 结果支持“历史变化传输值得研究”，只是没有证明“余量归一化是必要且可归因的创新”。

因此，合理决策是将 OHT 降级为工程候选或消融组件，而不是声称它已经被证明无用。

## 7. 以后做创新时应避免的错误

### 7.1 先写清真正的创新估计量

在实验前明确区分：

```text
方法相对基础模型的总收益
!=
核心新操作相对最强替代解释的增量收益
```

论文的核心结论必须对应第二项。若强对照复现了绝大部分收益，就应收缩或撤回创新叙事。

### 7.2 强对照必须独立调参且预算一致

不能让新方法使用为自己选择的门控、温度或早停点，再强迫对照共用。每个方法应拥有：

- 相同训练信息；
- 相同优化步数；
- 相同超参数搜索空间；
- 独立选择的最优参数；
- 相同模型选择规则。

### 7.3 首次机制验证就覆盖完整主范围

不要先在稀疏或最有希望的跨度上建立叙事，再把完整跨度当作后续补充。首次决策表至少应同时包含：

- 所有主预测跨度；
- 预期优势区间；
- 预期失败或保护区间；
- 结构负对照；
- 关键容量和状态分层。

### 7.4 使用正确的独立推断单位

时间序列事件在站点内高度相关。不能仅依靠事件级样本量或普通 bootstrap 获得过窄区间。跨站泛化任务应优先：

- 先在 seed 和事件层配对；
- 再聚合到站点；
- 以站点为 bootstrap 或层级模型的独立单位。

### 7.5 在扩大训练前设置不可协商的停止门

一个实用的阶段门可以是：

1. 代码和概率不变量通过；
2. 两个 seed 的方向一致；
3. 完整主范围没有不可接受的保护性损伤；
4. 相对强对照的效应达到预设最小实际意义；
5. 站点级置信区间排除 0；
6. 结果不能被更简单的校准或平移解释。

只要第 4–6 项未满足，就不应通过增加模块、seed 或正式训练来“抢救”叙事。

### 7.6 不要用额外复杂度掩盖机制失败

当核心机制没有通过匹配比较时，不应立即加入站点门控、多跨度门控、额外注意力、正则项或第二创新模块。新增复杂度会让失败原因更难定位，并增加事后选择空间。正确动作是冻结结果、记录失败、重新验证下一候选自己的必要前提。

### 7.7 区分方向性证据与可发表证据

“所有点估计同方向”“多数站点受益”都值得记录，但它们不等于置信区间排除零，也不等于达到实际意义阈值。报告中应明确使用以下词语：

- **方向性信号**：点估计一致，但不确定性仍跨 0；
- **统计支持**：预先指定区间排除无效区；
- **实际支持**：效应超过预设最小有意义阈值；
- **正式结论**：在冻结协议和未曝光测试集上复现。

OHT-NP 当前只达到第一层。

## 8. 下一候选的正确启动方式

OHT 失败后不能默认第二候选自动成立。任何新方向都应先完成自己的最便宜必要性检查。例如，若下一候选试图迁移概率分布的形状残差，应依次验证：

1. 在保持基础预测均值不变时，是否确实存在稳定的形状误差；
2. 简单的全局温度或离散度校正是否已经能解释该误差；
3. 支持窗残差是否比全局校准提供额外价值；
4. 因果残差是否来自交叉拟合，而不是训练标签重用；
5. 相对同信息、同参数规模的查询无关权重控制是否仍有增益。

只有这些必要条件逐层成立，才值得进入正式模型训练。

## 9. 结论

OHT-NP 提出了一个物理直觉清晰的边界感知变化传输规则，也在小范围实验中显示出稳定的方向性信号。然而，最关键的问题不是它能否击败未经传输的基础模型，而是它能否稳定击败普通增量平移。

在给两种方法独立且等预算地学习门控后，OHT 的六个跨度点估计全部更好，但站点级不确定性仍覆盖 0，额外收益远小于通用传输收益。因此，当前证据不足以把性能改善归因于余量归一化，核心创新判定为失败并停止扩展。

这次复盘最重要的经验是：**创新验证必须围绕最强替代解释设计，而不是围绕最容易击败的基础模型设计。**

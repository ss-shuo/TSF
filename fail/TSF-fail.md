# TSF 失败创新经验

> 范围：依据本目录 11 份复盘整理。这里的“失败”通常指在当前 UrbanEV 数据、冻结协议和开发门禁下，核心增量没有获得足够证据；不等于该思想在所有任务中永久无效。

## 1. 各方案留下的最小结论

| 方案                         | 原假设                                                | 失败点                                                                                                                 | 可迁移经验                                                                               |
| ---------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [CGOP](CGOP-fail.md)         | 用真实观测间隔的转移后验识别站点持续性                | 验证历史几乎连续，机制暴露不足；转移信息未稳定胜过水平后验，且 1--2 h 收益在 4--6 h 反转；聚合计数也难识别接口级转移   | 先统计目标困难的发生率和可识别性；多步任务必须逐跨度检查方向，不能只看总平均             |
| [COPPT](COPPT-fail.md)       | 从 168 h 历史识别站点日内相位错位                     | 平均分虽改善，但相位暴露率和受益站点比例未过门；收益由少数站点主导，水平适配解释了大部分价值；整数小时平移过于刚性     | “有周期”不等于“相位平移是主因”；均值改善、站点中位数、受益比例和机制覆盖必须同时成立     |
| [CLDP](COPPT-fail.md)        | 站点级水平-离散度后验优于全局离散度校正               | 未稳定胜过简单全局校正；区间增宽 19.25%，在已过覆盖时进一步损害校准                                                    | 后验可识别不等于有预测增量；必须同时评价 proper score、覆盖率、锐度和 PIT                |
| [CMoSA](CMoSA_fail.md)       | 在均值、二阶矩不变时迁移高阶形状残差                  | 早期正结果来自 source-fit/source-meta 职责混用；修正协议后 1--6 h 全部略差；高阶残差的可迁移性从未被独立证实           | 先审计数据职责再解释结果；协议污染后的有利结果必须作废并重跑                             |
| [LICDA](LICDA_fail.md)       | 隔日配对可隔离相邻日共同扰动并估计额外离散度          | 3 种子 x 6 跨度的关键相关差 18/18 方向相反；扣除计数噪声后额外离散度为负；短窗均值修正也不稳定                         | 漂亮推导前先做无训练相关诊断；配对数量充足不代表所选边包含目标信号                       |
| [OHT-NP](OHT-NP-fail.md)     | 按空闲/占用余量归一化后传输历史净变化，可改善边界行为 | 相对弱基线提升大，但相对独立调参的 ordinary shift 增量很小，全部站点 bootstrap 区间跨 0；初始对照还错误共用了 OHT 门控 | 真正的检验对象是新增归一化操作，而非“用了历史变化”；强对照必须独立、等预算调参           |
| [QIDT](QIDT-fail.md)         | 只更新历史和未来查询共同可辨识的依赖方向              | 联合依赖优于独立边际，但方向筛选未优于全方向收缩；多数方向都通过筛选，方法实际退化为普通收缩                           | 分开验证基础能力和创新增量；若选择器几乎不改变更新或最终 PMF，它只是复杂重述             |
| [QRCT](QRCT-fail.md)         | 风险系数监督加当前查询二次风险矩阵可形成更优组合      | 点估计最好但对局部 stacking/DIET 的配对区间跨 0；查询矩阵的独立作用近零；代理系数 MSE 的改善未稳定传到 dCRPS           | 代数分工不是性能贡献；逐段检查“表示 -> 权重 -> PMF -> 主指标”，并以最强局部基线作归因    |
| [CIST-Cal](CIST-Cal-fail.md) | 按离散 CDF 区间的可分辨方向做谱收缩                   | 小样本正信号扩大后翻转；同迹标量收缩更稳；谱诊断与收益近乎无关，且边界权重造成严重 NLL 尾损                            | 方向性正则前先证明诊断量能预测失效；求解成功和 PMF 合法不能替代尾部质量与主指标          |
| [CFMEP](CFMEP-fail.md)       | 保留前两阶阶乘矩并经 KL 投影重建 PMF                  | 虽优于 CAMP，却显著落后于同先验、同权重、同均值和同前两矩的零参数经验混合；KL 重建丢失有用高阶形状                     | 可解释矩不一定是充分统计量；完整分布指标下，先比较加权直方图、经验混合等最简单形状保留法 |
| [CCET-EV](CCET-EV-fail.md)   | 用快/慢充条件组成证据修正总占用分布                   | 仅 4/225 个验证站可受作用；混合站方差仅降约 2.23%，PMF 改变太小；组成似然与总量 dCRPS 脱节                             | 先算机制覆盖和 oracle 收益上限；辅助目标可预测不等于能改善主任务                         |
| [QCED-NP](QCED-NP-fail.md)   | 折减相关历史的重复证据，以修复过窄分布                | randomized PIT 显示基线实际偏宽；方法只能减证据并继续放宽；残差相关也不等于边际过窄，且支持密度变化不足                | 单向干预前必须确认失配方向；相关性只是动机，不是根因证据；方向错时应在训练候选模型前停止 |

## 2. 共同失败规律

1. **方法先于事实。** 多数方案先设计机制，后检查问题是否存在、出现多频繁、能否被当前数据识别。立项前必须量化机制暴露率、独立对象数、跨时间稳定性和 oracle 可达增益。
2. **把一般收益误归因于创新。** “目标历史有用”“依赖建模有用”“历史变化传输有用”都不等于相位、方向筛选或余量归一化有效。关键对照应与新方法共享数据、信息、输出族、训练预算和主要参数量，只删除唯一创新操作。
3. **压缩或代理目标与主指标错位。** 组成似然、风险系数 MSE、区间 NLL、前两阶矩或中间权重即使改善，也未必改善站点宏 dCRPS。必须实证验证代理量到最终 PMF、再到主指标的稳定传递。
4. **把正确性当成有效性。** 公式自洽、PMF 非负归一、矩约束满足、KKT 收敛、后验集中或可解释性，只证明实现了该方法，不能证明该方法必要或有效。
5. **平均值掩盖异质性。** 必须同时报告站点/坐标组配对区间、中位数、受益比例、各预测跨度、各时间块和机制子群；独立推断单位是站点或空间组，不是大量重叠小时行。
6. **小 pilot 被过度解释。** pilot 只用于查错和决定是否扩大；点估计为正但区间跨 0、只在少数跨度/日期成立或扩大样本后翻转，都不能升级为创新结论。
7. **概率质量检查不完整。** dCRPS、NLL、randomized PIT、覆盖率、区间宽度、真实标签最小概率和边界触达率要联合检查；区间变宽带来的分数改善可能以校准或锐度恶化为代价。
8. **数据与协议污染证据。** source-fit、source-meta、validation、calibration、test 必须职责隔离；测试集封存；对照独立调参；预测键、mask、容量、时间边界和 checkpoint/config 绑定均需在看结果前审计。
9. **数值合法性需覆盖反向传播。** 变容量 padding 必须在 `lgamma`、对数、除法等特殊运算前变为合法输入，输出端 mask 不能阻断 NaN 梯度；边界 Newton、网格触边、积分权函数和非标准 JSON `NaN` 都应显式失败而非静默回退。
10. **反证出现后继续堆复杂度会破坏归因。** 不应通过追加种子、网络、调参或解封测试集寻找正结果；先解释失败机制，若研究问题改变，则作为新方案重新预注册。

## 3. 下一方案的最小准入门

```text
问题门：基线缺陷存在，方向明确，覆盖足够多独立对象。
识别门：当前数据能区分目标机制与均值、日历、容量、缺失等替代解释。
上限门：oracle 干预能在主指标上产生有意义的最大收益。
归因门：最小实现稳定胜过同信息、同预算、只差一个操作的强简单对照。
稳健门：配对区间、受益比例、跨度、时间块、子群和概率质量同时合格。
工程门：角色隔离、键与 mask 对齐、容量支持、前向/反向有限性和边界行为全部通过。
扩展门：以上门均通过后，才做多种子、完整训练、校准和一次性最终测试。
```

总原则：**先证明问题存在，再证明机制可识别且有足够上限，最后证明新增操作相对最强简单解释具有稳定、广泛、可归因的主指标增量。**

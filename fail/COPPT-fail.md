# COPPT 失败复盘：容量约束占用相位后验迁移

## 摘要

COPPT（Capacity-Constrained Occupancy Phase Posterior Transfer，容量约束占用相位后验迁移）面向新充电站的短历史概率预测。它假设不同站点的日内需求模式存在稳定的整数小时错位，并尝试从目标站点最近 168 小时的观测中推断相位与占用水平，再将相位不确定性边缘化为容量合法的离散概率分布。

完整验证表明，COPPT 的平均预测分数优于仅调整占用水平的基线，但核心机制没有覆盖足够多的站点：相位暴露率为 28.34%，低于预设的 30%；受益站点比例为 45.10%，低于预设的 50%。因此，平均改善不能证明“相位错位是跨站迁移的普遍根因”，COPPT 未通过方法准入门。

备用方案 CLDP（Capacity-conditioned Level-Dispersion Posterior，容量条件水平—离散度后验）也未通过。它相对“水平后验 + 单一全局离散度校正”只取得不确定的平均增益，同时使预测区间增宽 19.25%，并让覆盖率进一步偏离标称水平。两条候选路线均失败后，实验按预设停止规则终止，没有继续叠加模块。

这次失败最重要的教训是：**创新方法必须证明目标机制真实存在、能够稳定识别、覆盖多数评价对象，并提供强简单基线无法解释的增益。平均指标变好只是必要条件，不是充分条件。**

## 1. 研究问题

任务使用 UrbanEV 数据集中的站点级充电桩占用快照。目标变量是每个站点在精确 `HH:55` 时刻的繁忙充电桩数量 `busy`，其合法取值为：

```text
0, 1, ..., C_s
```

其中 `C_s` 是站点总容量。实验研究未见站点的少样本预测：

- 全局模型只使用源站点训练数据；
- 每个目标站点可使用预测起点前 168 个小时槽；
- 168 个槽中至少需要 84 个有效观测；
- 预测未来 1–6 小时；
- 缺失观测保留显式 mask，不填充为零；
- 输出是容量范围内的离散 PMF；
- 同坐标站点组成一组，不能跨训练、验证、校准和最终评价集合。

这个任务的关键问题不是能否利用目标站点历史，而是目标历史中是否存在一种稳定、可识别且可迁移的结构，使新方法明显优于简单适配。

## 2. COPPT 的核心思想

### 2.1 假设

COPPT 的中心假设是：源模型已经学到一般性的日内占用形状，但目标站点的峰谷时间可能相对源模式提前或推迟。若这种错位在 168 小时支持窗中稳定存在，模型可以推断一个整数小时相位 `delta`，并据此修正未来预测。

水平变化是相位错位的主要竞争解释。某个站点整体更繁忙或更空闲，也会导致源模型拟合不佳。因此，COPPT 同时估计水平偏置 `a`，并通过 `level-only` 对照检验相位是否提供独立信息。

### 2.2 相位与水平后验

对 24 个整数小时相位逐一计算支持窗似然：

```text
delta in {0, 1, ..., 23}
```

对每个相位，估计带高斯先验的 logit 水平偏置：

```text
mu_t(a) = sigmoid(logit(mu_source,t) + a)
```

相位后验由支持窗的掩码似然形成：

```text
q(delta) = softmax((log_likelihood(delta) + log_prior(delta)) / tau)
```

预测阶段对全部相位进行概率混合：

```text
p(y_future | support)
  = sum_delta q(delta) * p_BB(y_future | capacity, delta, a_delta)
```

Beta-Binomial 输出保证所有概率质量位于 `0...C_s`，不会产生超过站点容量的预测。

### 2.3 必要对照

实验固定比较以下方法：

| 方法 | 作用 |
| --- | --- |
| `source` | 不使用目标站点历史 |
| `level-only` | 只调整目标站点占用水平，相位固定为 0 |
| `phase-only` | 只选择相位，水平固定 |
| `phase-MAP` | 使用后验概率最大的相位与对应水平 |
| `phase-mixture` | 对相位后验进行完整边缘化，即 COPPT |

真正决定 COPPT 是否成立的比较是 `phase-mixture` 对 `level-only`。它们使用相同数据、输出分布和基础模板，只在相位推断上不同。

## 3. 为什么先做低成本机制验证

直接训练大型神经网络无法回答相位机制是否存在。更强的主干可能提升总体分数，也可能掩盖错误假设。实验因此先使用从源训练期得到的容量分层 hour-of-week Beta-Binomial 模板，执行不涉及神经网络超参数搜索的 E0-Phase 验证。

E0 的准入条件在运行前固定：

| 检查 | 通过条件 |
| --- | --- |
| 相位暴露 | 至少 30% 合格 episode 的 `|delta_MAP| >= 1h` 且归一化后验熵不超过 0.7 |
| 分半稳定性 | 暴露 episode 中至少 60% 的前后半支持窗相位距离不超过 1 小时 |
| 主效果 | `phase-mixture - level-only` 的站点宏 dCRPS 配对 95% 区间上界小于 0 |
| 跨跨度稳定性 | 至少 4/6 个跨度不退化，且任何跨度相对退化不超过 1% |
| 跨时刻稳定性 | 三个预测起点时刻中至少两个改善 |
| 站点覆盖 | 超过 50% 的站点改善 |
| 概率质量 | NLL 与 WIS 不恶化，改善不能只靠扩大区间获得 |

这些门槛共同区分“少数样本贡献的大幅平均改善”和“可推广的机制收益”。

## 4. COPPT 的完整验证结果

完整验证覆盖 1,341 个合格 episode、153 个具有可评分查询的站点和 7,911 个查询单元。

### 4.1 总体结果

| 方法 | 站点宏 dCRPS | 站点宏 NLL | 站点宏 WIS |
| --- | ---: | ---: | ---: |
| `level-only` | 1.26457 | 1.77970 | 4.19402 |
| `phase-MAP` | 1.22944 | 1.77069 | 4.10067 |
| `phase-mixture` | **1.22546** | **1.77154** | **4.09492** |

`phase-mixture` 相对 `level-only` 的站点宏 dCRPS 差为 `-0.03910`，约改善 3.09%。配对坐标组/时间块 bootstrap 的 95% 区间为：

```text
[-0.09461, -0.00611]
```

六个预测跨度的平均 dCRPS 差均为负：

| 预测跨度 | dCRPS 差：mixture - level |
| ---: | ---: |
| H=1 | -0.01457 |
| H=2 | -0.04438 |
| H=3 | -0.05280 |
| H=4 | -0.03444 |
| H=5 | -0.04048 |
| H=6 | -0.05014 |

三个预测起点时刻也全部得到负的平均差。NLL 平均差为 `-0.00821`，WIS 平均差为 `-0.09879`。

### 4.2 未通过的核心门

| 核心门 | 结果 | 要求 | 判定 |
| --- | ---: | ---: | --- |
| 相位暴露率 | 28.34% | `>=30%` | 失败 |
| 暴露 episode 分半稳定率 | 62.89% | `>=60%` | 通过 |
| 改善站点比例 | 45.10% | `>50%` | 失败 |
| 站点差中位数 | +0.00023 | `<0` 更符合广泛改善 | 未改善 |

最终判定为 `STOP_A`。

## 5. COPPT 为什么失败

### 5.1 相位错位不是足够普遍的根因

只有 28.34% 的合格 episode 同时表现出非零相位和足够集中的后验。大多数支持窗没有提供明确的整数小时相位证据。相位模块可以改善部分序列，但无法作为整个跨站预测任务的中心解释。

这揭示了“周期明显”和“存在可迁移相位偏移”之间的区别。时间序列具有日周期，不代表站点之间主要通过水平平移后的时钟相位关系连接。幅度变化、周内结构、月份漂移、局部事件和缺失选择都可能产生类似残差。

### 5.2 平均改善由少数站点的大收益主导

整体 dCRPS 和配对区间看起来支持 COPPT，但只有 45.10% 的站点受益，站点差中位数接近零且略为正。负的平均差来自少数站点取得较大改善，而多数站点没有稳定受益。

这类结果不能支持“方法普遍改善跨站泛化”的主张。它最多说明相位适配对一个尚未提前识别的站点子集有价值。根据评价结果事后选择这些站点会造成选择偏差，因此不能用子集结果挽救主假设。

### 5.3 水平适配解释了目标历史的大部分价值

在 48 站 pilot 中，未经目标支持适配的 source 模板站点宏 dCRPS 为 2.16075；加入水平适配后降至 1.60267，改善幅度远大于相位混合相对水平适配的增量。完整验证也显示 `level-only` 已经是强控制项。

目标历史确实有用，但其主要信息是“该站点整体有多忙”，而不是“其日内模式相对源站点移动了多少小时”。把“目标历史有效”直接等同于“新相位机制有效”会错误归因。

### 5.4 整数小时循环相位过于刚性

COPPT 只移动 hour-of-day 表示，不移动日期、星期或真实目标顺序。这一限制保证了清晰归因，却只能表示 24 个整数小时状态。真实站点差异可能包括：

- 工作日和周末使用不同的峰值时刻；
- 峰值形状发生拉伸、压缩或分裂；
- 不同月份的峰值与幅度共同变化；
- 站点只有幅度变化，没有稳定相位变化；
- 168 小时窗口中的缺失使相位似然由少数时间段主导。

当数据生成机制超出循环平移时，增加相位状态无法解决错配。

### 5.5 Pilot 的正面信号没有在完整验证中保持

48 站 pilot 中，相位暴露率为 37.30%，平均 dCRPS 差为 `-0.08251`，配对区间上界小于零。但受益站点比例只有 39.58%，pilot 已经给出收益集中的警告。扩展到全部验证站后，相位暴露率降至 28.34%，触发停止条件。

Pilot 的作用是尽早发现明显失败和检查实现，不是代替完整验证。小样本中的平均改善容易受站点组成影响，不能作为进入正式训练的唯一依据。

## 6. 备用方案 CLDP 及其失败原因

### 6.1 CLDP 是什么

CLDP 放弃相位假设，只从支持窗更新两个低维变量：

- `a`：目标站点的 logit 水平偏置；
- `b`：Beta-Binomial 浓度参数的偏置，用于调整条件离散度。

查询分布对 `(a,b)` 的二维后验进行边缘化。它回答的问题是：目标历史除了提供占用水平，是否还提供站点特定、可稳定识别的离散度信息？

最强简单对照不是原始 `level-only`，而是：

```text
每个 episode 的 level 后验 + 全部验证支持窗共享的单一 global dispersion
```

只有 CLDP 明显优于这个对照，站点特定离散度后验才有独立价值。

### 6.2 数值网格首先暴露了实现问题

初始离散度网格范围为 `[-2,2]`。全局最优值落在 `+2` 上界，平均后验边界质量达到 44.38%。这说明网格截断了高似然区域，初始结果不具备解释资格。

修正只扩大离散度网格，不改变站点、查询、先验、水平网格或评价门。修正后的全局离散度 offset 为 7.25，位于网格内部；平均边界质量降至 2.00%。这次修正说明：**低维网格方法也必须检查最优点是否触边和后验边界质量。状态数小不等于数值实现自动可靠。**

### 6.3 修正后的 CLDP 结果

CLDP pilot 使用与 COPPT pilot 相同的 48 个站点、429 个 episode 和 2,510 个可评分查询。

| 方法 | 站点宏 dCRPS | 站点宏 NLL | 站点宏 WIS |
| --- | ---: | ---: | ---: |
| `level + global dispersion` | 1.50758 | 1.96046 | 4.90172 |
| `CLDP-MAP` | 1.50028 | 1.90009 | 4.76656 |
| `CLDP-mixture` | **1.49024** | **1.89773** | **4.74272** |

CLDP-mixture 相对强简单对照的结果为：

| 检查 | 结果 | 判定 |
| --- | --- | --- |
| dCRPS 平均差 | -0.01734 | 点估计改善 |
| dCRPS 95% CI | `[-0.07595, 0.01920]` | 跨零 |
| NLL 平均差 | -0.06274 | 点估计改善 |
| NLL 95% CI | `[-0.14247, 0.00310]` | 跨零 |
| WIS 查询单元平均差 | -0.14847 | 改善 |
| H=6 dCRPS 差 | +0.01249 | 退化 |
| 中容量层 dCRPS 差 | +0.00613 | 退化 |
| 查询单元平均区间宽度 | 7.0424 -> 8.3984 | 增宽 19.25% |
| 查询单元 80/90% 覆盖误差 | 0.1478 -> 0.2124 | 恶化 |

最终判定为 `PILOT_STOP_B`。

### 6.4 CLDP 为什么失败

CLDP 的后验离散度偏移十分明显，但“可识别”没有转化为“优于简单全局校正”。单一 global dispersion 已经捕获了验证集相对源模板的主要锐度变化。CLDP 的站点级后验继续增加不确定性，使区间明显变宽，而数据本身已经呈现过覆盖，导致覆盖误差进一步增大。

因此，CLDP 的平均 proper score 改善缺乏稳定的配对区间支持，也没有形成更好的校准—锐度折中。站点特定二维后验增加了复杂度，却没有提供强简单对照无法解释的收益。

## 7. 实验过程中出现的关键问题

### 7.1 只看平均指标会得出错误结论

COPPT 的平均 dCRPS、NLL、WIS、全部跨度和全部起点时刻都改善，配对 dCRPS 区间也不跨零。如果评价只包含这些数字，方法很容易被宣布为成功。

站点受益比例和站点差中位数给出了相反结论：改善不够广泛。跨实体任务必须同时报告平均效果、效果分布、改善实体比例和关键分层。

### 7.2 机制暴露必须早于复杂模型训练

相位暴露门只差 1.66 个百分点，但门槛的意义正是阻止研究者在看到结果后放宽标准。若先训练完整 DeepAR-COPPT，再检查相位是否存在，大量计算投入会制造继续解释结果的心理压力。

低成本机制门节省了正式训练成本，并及时删除了无法支撑的中心叙事。

### 7.3 强简单基线必须与新方法共享信息

`source` 不是 COPPT 的关键对照，因为它没有使用目标支持窗。`level-only` 才能判断相位是否提供超出目标历史水平信息的增益。同理，CLDP 必须对比 `level + global dispersion`，不能只对比固定离散度模型。

弱基线会把“使用了更多信息”伪装成“新机制有效”。

### 7.4 后验混合可能通过增宽区间改善部分分数

边缘化参数不确定性通常会扩大预测分布。区间变宽可能改善 NLL 或 WIS，却不一定改善校准。在已经过覆盖的模型上继续增宽，会让覆盖率离标称值更远。

概率预测必须同时检查 proper score、覆盖率、区间宽度和 PIT 形态。任何“通过增加不确定性得到的改善”都需要证明其校准—锐度折中更好。

### 7.5 网格触边是模型实现失败信号

初始 CLDP 网格把最优离散度限制在上界。若忽略触边和边界质量，研究者可能把数值截断产生的结果解释为统计结论。所有网格后验都应至少检查：

- MAP 是否位于边界；
- 边界状态的总后验质量；
- 扩展网格后结论是否稳定；
- 参数化在零偏置处是否精确恢复基础模型。

### 7.6 模板验证通过不代表神经版本必然失败

本次 E0 检验的是创新机制能否在低成本、同信息模板中暴露并产生广泛增益。它没有训练完整 DeepAR-BB 主干。结论是“现有数据与协议不足以支持把相位后验作为中心创新并投入正式训练”，而不是“所有神经相位模型在任何数据上都无效”。

这个边界同样重要：失败复盘应准确删除未经支持的研究路线，不能把局部否证扩大成普遍定理。

## 8. 保留下来的有效资产

方法候选失败，但以下实验资产仍然有效：

1. **明确的预测对象**：目标是容量有界的站点占用数快照，不把聚合占用解释为车辆到达、停留或接口级过程。
2. **零与缺失分离**：合法 `busy=0` 与观测缺失使用不同语义，查询缺失不插值、不计分。
3. **固定 few-shot 协议**：168 小时支持、至少 84 个有效观测、未来 1–6 小时预测。
4. **坐标组隔离**：同坐标多 ID 站点不跨数据池，降低空间身份泄漏。
5. **时间职责隔离**：训练、方法选择、校准、最终评价和压力测试使用不同月份。
6. **容量合法 PMF**：每个站点的概率支持严格限制在 `0...C_s`。
7. **由简到繁的归因链**：`source -> level -> new mechanism`，先证明简单适配，再检验新增机制。
8. **预设停止规则**：候选失败后终止模块叠加，避免通过反复试验制造偶然成功。

这些资产可以服务后续研究，但不应被重新包装为方法创新。

## 9. 下一次创新研究的检查清单

### 9.1 立项前：先证明问题存在

- 用不依赖新模型的统计量直接测量目标机制的暴露率。
- 检查机制能否在不同时间切片中重复识别。
- 同时列出至少两个竞争解释，并为每个解释设计简单控制项。
- 若机制只存在于少数对象，先建立可提前识别的适用条件，再定义总体主张。

### 9.2 实现前：冻结最强简单对照

- 新方法使用目标历史时，基线必须使用相同长度和相同字段的目标历史。
- 新方法调整多个参数时，分别建立单参数对照和全局参数对照。
- 输出分布、预测支持和评分器必须一致。
- 不用未经适配的 source 模型充当唯一基线。

### 9.3 Pilot 阶段：验证机制和代码，不确认结论

- Pilot 站点在查看查询结果前固定。
- 同时报告均值、中位数、改善站点比例和分层结果。
- 检查结果是否由少数大幅改善对象主导。
- 检查参数后验是否触边、退化或由先验主导。
- Pilot 只决定是否值得扩大验证范围，不授权最终测试。

### 9.4 完整验证：设置多维准入门

- 主 proper score 的配对区间必须支持改善。
- 多数站点应受益，或存在提前定义且可识别的适用子群。
- 多数预测跨度和业务时刻应保持方向一致。
- NLL、CRPS、WIS、覆盖率和宽度应形成一致证据。
- 任何门槛失败都按预设动作处理，不在看到结果后改阈值。

### 9.5 概率模型：同时评价校准与锐度

- 记录 50%、80%、90% 区间覆盖率和宽度。
- 在过覆盖时警惕后验混合继续增宽分布。
- 在欠覆盖时区分分布族错配、全局离散度偏差和站点特定偏差。
- 先尝试单一全局校正，再证明局部后验的独立价值。

### 9.6 停止规则：失败后不要继续堆模块

- 中心机制不暴露时，删除该机制主张。
- 简单对照解释全部增益时，将其保留为工程基线。
- 备用候选也失败时，停止方法扩展。
- 不通过增加随机种子、搜索更多超参数或查看测试集来寻找显著性。
- 负结果可以形成协议、诊断或数据研究，但不能继续使用原创新叙事。

## 10. 可迁移的结论

COPPT 失败的根本原因不是平均分没有改善，而是证据无法支持其中心机制具有足够的普遍性。相位后验对部分站点有效，但相位暴露不足，多数站点没有受益；CLDP 又表明，增加站点级离散度后验不能稳定胜过单一全局校正，并破坏了校准—锐度折中。

后续创新应遵循以下顺序：

```text
机制暴露
  -> 可识别性与稳定性
  -> 强简单对照
  -> 小范围增量验证
  -> 跨对象广泛性
  -> 概率质量与校准
  -> 正式模型训练
```

任何一步失败，都应先修正研究问题，而不是增加模型复杂度。这比得到一个短期更高的平均分更重要。

## 11. 数据与结果边界

本复盘基于 UrbanEV 公开数据集的固定版本，研究对象是同一城市、同一平台、六个月观测期内的站点占用数概率预测。结论适用于本文定义的 `HH:55`、168 小时支持、1–6 小时预测和跨站点验证协议。

# QCED-NP 失败复盘：查询相关证据去冗余为何没有进入正式比较

> 文档日期：2026-09-17  
> 方法简称：QCED-NP（Query-Conditioned Evidence De-redundancy Neural Process）  
> 失败类型：核心前提方向错误，触发预先设定的分支停止规则  
> 结论范围：否定本任务和当前概率接口下继续开发 QCED-NP 的必要性，不证明该方法在所有数据集上恒定无效

## 1. 一句话结论

QCED-NP 原本要解决“相关历史被重复计为独立证据，导致预测分布过窄”的问题，但正式 CAMP-R 基线的 randomized PIT 显示预测分布已经显著偏宽。QCED-NP 只能减少有效证据、进一步放宽分布，干预方向与实际问题相反，因此在训练 QCED-NP 之前停止该创新分支。

## 2. 研究任务

任务是在未见过的电动汽车充电站上，根据最多 168 小时的历史状态，预测未来 1 至 6 小时的占用充电枪数量分布。

目标具有明确的有限支持集：若站点容量为 $C_s$，则未来占用数满足

$$
Y_q \in \{0,1,\ldots,C_s\}.
$$

实验使用 UrbanEV 公开数据版本 423269（DOI：`10.5061/dryad.np5hqc04z`）。主要数据事实如下：

| 项目 | 数值或规则 |
| --- | --- |
| 站点数 | 1682 |
| 精确坐标组数 | 1543 |
| 规范小时记录数 | 7,306,608 |
| 小时缺测率 | 21.38% |
| 时间采样 | 每小时精确 `HH:55`，不插值标签 |
| 支持窗口 | 0、72 或 168 小时；正式验证固定 168 小时 |
| 预测跨度 | 1 至 6 小时 |
| 站点划分 | 精确坐标组整体划分，避免同址站点泄漏 |
| 主要制度 | 未见站点少样本预测 |

数据划分先按坐标组完成，再生成时间情节。训练、验证、校准和测试站点互不交叉。未来标签是否可观测只用于损失和计分，不进入模型输入，也不用于筛选需要发布预测的情节。

## 3. 原创新假设

### 3.1 观察动机

充电占用序列具有持续性。相邻小时的状态往往相似，因此 168 个历史槽不等于 168 份独立信息。如果模型把相邻记录逐条累加为证据，可能高估证据总量，使 Beta-Binomial 分布过度集中。

### 3.2 可证伪假设

原假设是：

> 在未见站点的固定短历史预测中，相比同信息、同预算的普通证据可靠性学习，按查询相关的两两时间冗余折减占用/空闲证据，可以改善容量有界的概率预测；收益不能完全归因于普通收缩、均值修正或注意力。

这个假设隐含三个必须同时成立的前提：

1. CAMP-R 的主要剩余问题是分布过窄，而不是过宽或均值错误。
2. 过窄与支持记录的时间相关性或支持密度有关。
3. 减少有效证据量能够按正确方向修复该问题。

任何一个前提失败，都不应继续训练 QCED-NP。

## 4. 核心方法是什么

### 4.1 CAMP-R 基线

对历史记录 $i$ 和未来查询 $q$，模型产生非负证据权重

$$
u_{iq}=m_i\operatorname{softplus}\big(g_\theta(e_i,e_q,t_q-t_i)\big),
$$

其中 $m_i$ 是历史观测掩码。令占用比例为 $v_i=y_i/C_s$，查询先验为 $a_{0q},b_{0q}>0$，则 CAMP-R 直接累加证据：

$$
S=\sum_i u_i,
$$

$$
a_q=a_{0q}+\sum_i u_i v_i,
\qquad
b_q=b_{0q}+\sum_i u_i(1-v_i).
$$

最终输出容量有界的 Beta-Binomial 分布：

$$
Y_q\sim\operatorname{BetaBinomial}(C_s,a_q,b_q).
$$

### 4.2 QCED-NP 的创新操作

QCED-NP 不改变证据加权均值，只减少证据总量。它使用查询相关的非负时间相关矩阵：

$$
R_q=\pi_{0q}I+\sum_{r=1}^{3}\pi_{rq}K_r,
$$

$$
(K_r)_{ij}=\exp\left(-\frac{|t_i-t_j|}{\ell_r}\right),
\qquad \ell=(1,6,24)\text{ 小时},
$$

其中 $\pi_q$ 由查询特征产生且和为 1。定义

$$
A=\sum_i u_i^2,
\qquad
D=u^\top R_q u,
\qquad
r=\frac{A}{D},
$$

$$
S_{\mathrm{eff}}=rS.
$$

由于 $R_q$ 非负且单位对角，设计上有

$$
0<r\le 1.
$$

因此 QCED-NP 只能保持或减少证据，不能增加证据。更新为

$$
\bar v=\frac{\sum_i u_iv_i}{S},
$$

$$
a_q=a_{0q}+S_{\mathrm{eff}}\bar v,
\qquad
b_q=b_{0q}+S_{\mathrm{eff}}(1-\bar v).
$$

当 $R_q=I$ 时，$r=1$，模型严格退化为 CAMP-R。

### 4.3 方法的方向性限制

减少 $a_q+b_q$ 通常会放宽预测分布并增强向先验的收缩。因此，这个方法只适用于“基线过度集中”这一方向。若基线已经过宽，QCED-NP 的核心操作会沿错误方向继续移动。

这个方向性限制是本次失败的关键。

## 5. 实验如何执行

为避免在候选方法上浪费预算，实验预先设置了基线门槛：先训练一次 CAMP-R，再判断是否存在需要去冗余的概率失配。只有前提成立，才允许训练强标量可靠性模型和 QCED-NP。

首次正式运行采用：

| 项目 | 设置 |
| --- | --- |
| 站点组划分种子 | 20260913 |
| 训练种子 | 17 |
| 隐藏宽度 | 64 |
| 点编码器层数 | 3 |
| 优化器 | Adam |
| 学习率 | 0.001 |
| 批量大小 | 32 |
| 每轮训练步数 | 100 |
| 最大轮数 | 30 |
| 早停耐心 | 5 |
| 训练损失 | 离散 CRPS |
| 选模指标 | 验证站点宏平均离散 CRPS |

正式 CAMP-R 在第 30 轮取得最佳验证结果。由于最佳点位于训练上限，不能声称训练已经充分收敛；但后续停止依据不是模型间微小性能差异，而是预测分布失配方向与 QCED-NP 的作用方向相反。

本次只消耗了 1 次正式神经训练。没有训练 QCED-NP，没有训练强标量对照，也没有打开校准集或测试集。

| 可计分查询数 | 121,900 |
| 有可观测标签的站点数 | 233 |
| 对应坐标组数 | 230 |
| 重复 `(station, origin, horizon)` | 0 |

### 6.2 基线性能

| 指标 | 数值 |
| --- | ---: |
| 验证站点宏平均离散 CRPS | 0.79713 |
| 查询微平均离散 CRPS | 0.74973 |
| MAE | 1.02139 |
| 平均残差 | -0.00434 |
| 原始 MSE | 5.76432 |
| 90% 区间平均宽度 | 4.69538 |
| 90% 区间覆盖率 | 96.86% |
| 覆盖率坐标组 bootstrap 95% 区间 | 95.86% 至 97.61% |

平均残差接近 0，说明总体方向偏差不大；但总体均值正确并不表示每个站点和跨度都没有均值误差。

### 6.3 均值误差与集中度分解

按“站点×预测跨度”去除固定均值偏差后：

| 指标 | 数值 |
| --- | ---: |
| 去均值 MSE | 5.00675 |
| 系统性站点×跨度偏差 MSE | 0.75757 |
| 系统性偏差占原始 MSE | 13.14% |
| 平均预测方差 | 3.83747 |
| 去均值残差方差/预测方差 | 1.32114 |
| 上述比值的组 bootstrap 95% 区间 | 0.79567 至 2.07306 |

该方差比点估计大于 1，但不确定区间很宽并跨过 1，不能单独证明模型过窄。少量高误差站点会显著影响平方误差，而中央预测区间和完整分布校准可能给出不同信号。因此不能只用 MSE/方差比决定概率分布是宽还是窄。

### 6.4 Randomized PIT：决定性诊断

离散分布的等尾区间天然可能保守，所以 96.86% 的覆盖率本身不足以证明预测过宽。为排除这一解释，使用 randomized probability integral transform（randomized PIT）：

$$
U=F(Y-1)+V\,p(Y),
\qquad V\sim\operatorname{Uniform}(0,1).
$$

若预测分布校准良好，$U$ 应近似服从 $\operatorname{Uniform}(0,1)$，其方差为 $1/12$。结果如下：

| PIT 指标 | 数值 |
| --- | ---: |
| PIT 均值 | 0.50288 |
| PIT 均值 bootstrap 95% 区间 | 0.49683 至 0.50938 |
| PIT 方差/均匀分布方差 | 0.78847 |
| 方差比 bootstrap 95% 区间 | 0.75259 至 0.82794 |
| PIT 落在中央 80% 的比例 | 85.69% |
| PIT 落在最外侧 10% 的比例 | 7.57% |

PIT 均值接近 0.5，未显示明显的总体方向偏差；PIT 方差显著小于均匀基准，直方图在中部隆起。这是预测分布过宽的直接证据，而且不依赖离散等尾区间是否天然保守。

### 6.5 时间残差相关性

按站点和跨度去均值后，残差时间相关为：

| 时间间隔 | 相关系数 | 坐标组 bootstrap 95% 区间 |
| --- | ---: | --- |
| 6 小时 | -0.06599 | -0.14492 至 0.06077 |
| 12 小时 | -0.02134 | -0.08807 至 0.02961 |
| 24 小时 | 0.25675 | 0.10672 至 0.37921 |

24 小时相关显著存在，说明仍有未建模的日周期结构。但“残差存在时间相关”不等于“历史证据被重复累计后造成过度集中”。本次实验正好展示了两者不能互相替代：24 小时相关存在，同时预测分布整体仍然偏宽。

### 6.6 支持密度关联

使用站点×跨度固定效应，分析以下结果变量：

$$
\frac{\text{去均值残差平方}-\text{预测方差}}{C_s^2}.
$$

支持比例的标准化系数为：

$$
-0.000805,
$$

坐标组稳健 95% 区间为

$$
[-0.001514,-0.000096].
$$

方向与原假设相反：支持更密集时，超额离散程度没有上升，反而下降。最近观测年龄的关联区间跨过 0，不能支持“观测越新、重复证据越严重”。

该分析的识别能力也受数据分布限制：

| 支持特征 | 比例 |
| --- | ---: |
| 168 个支持槽全部可观测 | 91.53% |
| 最近观测年龄为 0 小时 | 99.48% |

大多数可计分查询几乎没有支持密度变化，因此这个数据切片并不适合精确识别“缺测间隔或支持密度如何调节过度集中”。这不是可以通过增加网络层数解决的问题。

## 7. 为什么创新失败

### 7.1 首要原因：根因判断错误

创新假设把剩余误差归因于“证据重复导致过度集中”，但 randomized PIT 显示基线显著过宽。问题方向判断错误后，后续精巧机制没有继续开发的价值。

### 7.2 干预只有单向能力

QCED-NP 的 $r=A/D$ 满足 $r\le 1$，只能减少有效证据。它不能在基线过宽时增加证据或收紧分布。因此它不是一般性的校准机制，而是只针对过度集中的单向修正。

一个只能向单一方向调整的方法，必须在设计前获得非常强的方向证据。本项目没有在提出方法前拥有这种证据。

### 7.3 把时间相关误当成概率过度集中

序列有时间相关是事实，但它可能造成均值遗漏、周期偏差、尾部错误或联合路径依赖，不必然造成边际分布过窄。本次结果中，24 小时残差相关显著，而 PIT 同时显示边际分布偏宽，直接否定了二者的简单等价关系。

### 7.4 支持变化不足，机制难以识别

91.53% 的可计分样本拥有完整 168 小时支持，99.48% 的最近观测年龄为 0。缺少足够的支持密度和时间间隔变化，使“冗余效应随支持结构变化”的主张难以被数据识别。

在缺乏暴露变化时，模型即使取得性能差异，也难以把收益归因到目标机制。

### 7.5 单看区间覆盖或单看方差比都会误判

90% 区间覆盖率高于 90% 可能来自离散分布的保守性；MSE/预测方差比大于 1 又可能来自少数尾部误差。二者给出了表面冲突的信号。randomized PIT 使用完整离散 PMF 后，才明确识别出中央分布过宽。

因此，有限计数概率模型必须优先检查 randomized PIT、proper score 和区间质量的组合，而不能只看其中一个统计量。

### 7.6 基线训练到预算上限

最佳检查点出现在第 30 轮，即最大轮数。它提示当前训练预算可能尚未显示完整收敛形态。这会限制对绝对性能的解释，但不推翻停止决定：当前已训练分布的失配方向与 QCED-NP 的单向折减方向相反，继续训练候选模型不能回答其必要性。

### 7.7 证据只支持停止分支，不支持普遍否定

本次只运行了一个划分和一个训练种子的 CAMP-R，没有训练 QCED-NP，也没有做多种子模型比较。因此可以得出的结论是：

> 在当前任务、数据切片、基线配方和预先设定的门槛下，没有依据继续投入 QCED-NP。

不能写成：

> 时间去冗余方法在所有概率预测任务中都无效。

## 8. 实现过程中出现的数值问题

### 8.1 症状

首次正式训练在第 1 轮第 57 步出现非有限损失。重放发现第 56 步的前向损失仍为有限值，但反向传播已经产生 NaN 梯度；优化器更新后，第 57 步才表现为 NaN loss。

### 8.2 根因

不同站点容量不同，批内 PMF 被填充到统一的最大容量。对容量为 $C$ 的站点，$k>C$ 的位置最终会被掩码为零，但旧实现先计算了

$$
\log\Gamma(C-k+1)
$$

等非法项，再执行掩码。

前向传播中，掩码后的概率看起来完全正常；反向传播仍会经过特殊函数在极点附近的导数，产生 NaN。这是“前向有限、反向不有限”的典型陷阱。

### 8.3 修复原则

容量外的填充位置在进入 `lgamma` 前先映射到合法边界：

$$
k_{\mathrm{safe}}=\min(k,C),
$$

所有特殊函数只接收合法参数，最后再把 $k>C$ 的位置设为零概率。修复后，在完全相同的随机种子、批量大小和采样序列下重放，训练顺利越过原故障点。

### 8.4 工程教训

1. 掩码输出不等于屏蔽了无效计算的梯度。
2. 概率分布测试必须同时覆盖前向归一性和反向梯度有限性。
3. 变容量、变类别数或 padding 场景必须在特殊函数之前处理非法状态。
4. 梯度裁剪应启用非有限范数检查，不能让 NaN 梯度进入优化器。
5. 应使用原随机序列精确重放故障，而不是只跑一个更小的 smoke batch。

## 9. 哪些做法是正确的

这次失败没有演变成大规模无效实验，原因是研究流程中保留了以下约束：

1. 在候选模型训练前设置了 CAMP-R 根因门槛。
2. 校准集和测试集没有被用于决定是否继续创新分支。
3. 失败后没有不断更换种子寻找有利结果。
4. 没有因为已经实现了 QCED 核心公式就强行完成全部 30 次训练预算。
5. 使用恒等核退化检查，确认 QCED 接口可以严格恢复 CAMP-R。
6. 使用坐标组而非单站点作为不确定性抽样单位，避免同址站点被当成独立证据。
7. 补充 randomized PIT 后才做最终方向判断，避免被离散区间覆盖率误导。

这些内容可以保留到后续项目：防泄漏数据协议、容量有界 Beta-Binomial 头、稳定离散 CRPS、randomized PIT、坐标组 bootstrap、空支持接口、概率边界测试和线性时间指数核递推。

## 10. 以后做创新前必须回答的问题

### 10.1 根因检查

- 强基线究竟是均值错、分布过宽、分布过窄、尾部错，还是联合路径错？
- 主要 proper score、randomized PIT、覆盖率、宽度和点误差是否给出一致结论？
- 现象在控制容量、跨度、站点偏差和支持数量后是否仍存在？
- 数据中是否有足够的目标机制变化，能够识别所声称的因果方向？

### 10.2 方法方向检查

- 新操作能把模型向哪个方向移动？
- 它能双向调整，还是只能扩大/缩小、平滑/锐化？
- 基线诊断是否明确支持该方向？
- 若真实问题方向相反，方法能否退化为恒等映射而不伤害结果？

### 10.3 替代解释检查

- 普通标量温度、可靠性网络或后处理校准能否解释预期收益？
- 时间相关是否只是遗漏的季节均值，而不是证据重复？
- 性能变化是否来自额外输入、参数量、训练轮数或数据筛选？
- 是否把相关性、校准性和不确定性分解混成了一个概念？

### 10.4 数值实现检查

- 所有合法容量的 PMF 是否归一化？
- 容量外概率是否严格为零？
- 最小/最大容量、空支持和全缺测支持是否有定义？
- 前向值、损失、梯度和优化后参数是否全部有限？
- padding 位置是否在进入 `log`、`lgamma`、除法和矩阵分解之前已经合法化？
- 恒等退化是否与基线逐元素一致？

### 10.5 实验停止检查

- 在训练候选模型前，是否写明了什么结果会停止该分支？
- 根因不成立时，是否愿意保留负结果而不是修改故事？
- 是否能在不打开测试集的情况下作出分支决定？
- 一次种子结果的证据边界是否被明确记录？

| PIT 方差显著小于均匀基准 | 不使用只能减少证据的方法；先研究锐化、先验或证据不足问题 |
| PIT 均值明显偏离 0.5，且均值误差占主导 | 先修复均值模型，不把问题包装成不确定性创新 |
| 只有残差时间相关，分布集中度没有同向失配 | 研究季节均值、动态状态或联合路径，不直接推出证据重复 |
| 支持数量和缺测间隔几乎没有变化 | 更换可识别该机制的数据或缩小主张，不依赖复杂网络强行归因 |
| 多项诊断方向冲突 | 增加完整 PMF 诊断和分层分析，暂不训练候选模型 |

## 12. 最终失败判定

QCED-NP 的数学构造可以运行，恒等退化和线性递推也通过了实现检查；失败不在于公式无法计算，而在于公式试图修复一个没有按预期方向出现的问题。

正式基线给出的证据链为：

1. CAMP-R 的 randomized PIT 显著中部隆起，预测分布偏宽。
2. QCED-NP 的核心比例 $r\le1$，只能减少有效证据并进一步放宽分布。
3. 24 小时残差相关存在，但不能推出边际分布过窄。
4. 支持密度与超额离散的关联方向不支持原假设。
5. 数据中支持密度变化不足，难以建立目标机制归因。

因此，本创新分支的正确处理是停止，而不是继续训练后再从结果中寻找新的解释。

最应保留的经验是：**先证明问题存在、方向正确且能够被数据识别，再设计只能沿该方向工作的机制。相关性是动机，不是根因证据；可运行的公式也不是值得继续实验的理由。**

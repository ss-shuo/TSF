# CAMP-NP Reference：容量锚定单调伪计数神经过程的可取之处与不足

> 本文是对 CAMP-NP（Capacity-Anchored Monotone Pseudo-count Neural Process）方案的技术复盘，目标是提炼以后做创新时可以迁移的思想，同时明确哪些做法不能直接照搬。文中只讨论方法、证据和适用边界，不依赖任何本地环境或仓库路径。

## 1. 一句话看懂这个创新

CAMP-NP 面向“训练中没有见过的新充电站”，在只知道站点容量、日历信息和一段不完整短历史的条件下，直接输出未来占用数量的完整概率分布，而不是只输出一个点预测。

它的核心做法是：

1. 用源站点数据学习一个面向查询时刻的先验；
2. 把每个有效历史小时看成一条“占用/空闲证据”，而不是简单的序列元素；
3. 用查询相关的非负权重决定每条证据贡献多少；
4. 将占用证据和空闲证据累积为 Beta 参数；
5. 用站点容量作为 Binomial 试验数，解码为 Beta-Binomial PMF，使预测概率严格落在 `0, ..., C_s` 的物理支持集内。

最重要的思想不是“使用了 MLP、注意力或 Beta-Binomial”这些具体组件，而是：**把任务中的物理约束、观测语义和不确定性表示统一到同一个可学习的更新接口中。**

## 2. 它真正创新在哪里

### 2.1 从“预测序列”转向“聚合证据”

传统循环模型倾向于把历史压缩成一个隐状态；普通 CNP 倾向于对上下文表示做池化。CAMP-NP 改变了问题表述：历史中的每个有效观测都被解释为对未来查询的部分证据。

对一个上下文小时 `i` 和查询 `q`，模型先计算非负权重 `u_iq`，再分别更新占用和空闲参数：

```text
a_q = a_q^0 + Σ u_iq · y_i / C_s
b_q = b_q^0 + Σ u_iq · (1 - y_i / C_s)
```

这样做带来一个有意义的结构性质：在查询和已有表示固定时，加入有效观测只会增加占用证据、空闲证据，或同时增加二者，不会以任意方式抵消已有证据。

这比“让网络自由地把历史映射到两个参数”更容易解释，也更贴近 Beta-Binomial 的共轭更新直觉。

### 2.2 把物理容量作为概率分布的结构，而不是事后修正

充电站占用数满足 `Y ∈ {0, ..., C_s}`。无界 Poisson 或负二项分布即使均值预测准确，也可能给超过容量的数量分配概率。

CAMP-NP 直接用容量 `C_s` 作为 Binomial 试验数，最后得到支持集严格为 `0, ..., C_s` 的分布。因此，越界概率不是“训练后尽量变小”，而是由分布族定义为零。

这体现了一个可迁移原则：**如果领域约束是硬约束，应尽量放进输出分布或参数化本身，而不是依赖惩罚项、后处理或阈值修剪。**

### 2.3 将 zero-shot 与 few-shot 统一为同一条前向路径

当上下文为空时，两个证据和为零，模型自然退化为查询先验；当上下文长度为 168 小时时，使用同一套更新公式。这种接口统一避免了为 zero-shot 和 few-shot 维护两套模型。

这里的价值主要是工程和协议上的一致性，而不是已被证明的 zero-shot 性能优势。实验显示，CAMP-NP 的 zero-shot 先验并不优于经验贝叶斯季节先验；它的优势主要在使用目标站历史之后出现。

### 2.4 将模型设计与可证伪对照绑定

方案没有只报告“完整模型优于基线”，而是设置了一组有明确角色的对照：

| 对照      | 要检验的问题                       | 结论边界                                           |
| --------- | ---------------------------------- | -------------------------------------------------- |
| E6 vs E5  | 结构化非负更新是否优于普通池化 CNP | 支持“完整结构化更新”的整体价值；不能拆出每个子组件 |
| E4 vs E3  | 精确有界支持本身是否有帮助         | 支持小幅收益，UrbanEV 约 2.8%，北京约 3.5%         |
| E6 vs E7  | 查询相关权重是否重要               | 方向一致，但参数量不匹配，只能作为辅助证据         |
| E6 vs E8  | 容量是否需要进入先验头             | 未支持容量相关先验带来实质收益                     |
| E9 vs E6  | 更灵活的混合分布是否更好           | 未建立混合形状族的优势，且稳定性较差               |
| E6 vs E10 | 概率分布模型与点预测模型的目标差异 | CAMP-NP 的优势不是点误差                           |

这种“每个设计点预先写出替代方案”的做法，比单纯增加更多基线更有解释力。

## 3. 实验真正支持了什么

### 3.1 支持的主结论

在严格留站的 UrbanEV 盲测中，CAMP-NP 的平均 CRPS 为 0.731：

- 相比 DeepAR-NB 的 0.834，CRPS 降低约 12.4%；
- 相比参数量匹配的普通 Beta-Binomial CNP（0.819），CRPS 降低约 10.8%；
- 相比有界循环对照 E4（0.811），仍有约 9.8% 的降低。

在北京数据上，方向保持一致：CAMP-NP 为 0.515，普通 CNP 为 0.675；不过北京的 E3–E5 比较属于揭盲后的机制扩展，不应与正式冻结盲测混为同一证据等级。

收益具有三个特征：

1. 主要体现在概率分布质量，而不是点预测误差；
2. 主要集中在 3–6 小时预测，1 小时并不占优；
3. 完整结构化更新的收益明显大于单独施加有界支持的收益。

### 3.2 支持集约束的收益相对有限

无界 DeepAR-NB 存在容量外概率质量，UrbanEV 平均越界质量约为 0.0478。将其改为有界支持后，CRPS 的改善约为 2.8%（UrbanEV）和 3.5%（北京）。

这说明：**物理约束是必要的，但仅仅把输出截断到合法范围，并不能替代好的上下文更新机制。**

### 3.3 点预测不是它的强项

UrbanEV 上，DeepAR-NB 的均值 MAE 约为 0.915，CAMP-NP 约为 1.027；N-HiTS 点模型约为 0.591。由此可见，CAMP-NP 不应被宣传为全面优于所有预测器，而应定位为面向概率决策的分布预测器。

## 4. 最值得借鉴的思想

### 4.1 先找“任务结构”，再选网络结构

可迁移的顺序应是：

1. 明确目标变量的物理支持、守恒关系或可行域；
2. 判断历史观测在任务中代表什么语义（样本、证据、状态、约束还是事件）；
3. 设计能够保留这些语义的参数更新；
4. 最后再选择 MLP、注意力、循环网络或其他实现。

CAMP-NP 的价值正在于先做了第 1–3 步，而不是先堆叠一个更大的网络。

### 4.2 把不变性和单调性写进模型

非负证据累加、容量支持约束、缺失掩码为零，都是可验证的结构性质。它们比“训练后观察到模型似乎遵守规律”更可靠。

以后设计创新时，可以主动寻找：

- 哪些量只能增加、不能减少；
- 哪些输出不可能超过上限或低于下限；
- 哪些信息缺失时应当完全不产生贡献；
- 哪些更新应当与输入顺序无关。

然后把这些性质放进参数化，而不是只写在损失函数或说明文字里。

### 4.3 用“可解释中间量”连接输入和输出

占用伪计数和空闲伪计数是很好的中间表示：它们既保留了概率模型的含义，又允许神经网络学习查询相关性。

一般化地说，创新方法可以寻找一个中间状态，使得：

- 中间量有清晰语义；
- 输入对中间量的贡献可检查；
- 中间量能自然映射到最终输出；
- 对照实验能针对中间量的替代方式设计。

### 4.4 让评价指标与应用决策一致

如果应用需要容量风险、拥堵概率或区间，而不是单个均值，就应使用完整 PMF、CRPS、校准、Brier 等指标，而不能只报 MAE。

同样，若最终应用只需要点预测，就不应因为概率模型的 CRPS 更好而宣称它全面更优。

### 4.5 对“不能识别”的部分主动降级表述

E6 与 E5 的比较支持的是“完整结构化更新”，而不是分别证明：

- 查询相关性单独贡献多少；
- 非负加性单独贡献多少；
- Beta-Binomial 分布族单独贡献多少。

这是因为多个因素同时发生变化，且 E7 的参数量也不匹配。以后做消融时，应提前画出“改变了哪些因素—能识别什么—不能识别什么”的表格，避免把组合效果写成单组件因果效果。

## 5. 不足、风险与不可取之处

### 5.1 组件贡献没有被完全隔离

E6 vs E5 同时改变了上下文聚合和参数更新头；因此不能据此断言某一个子模块就是主要原因。E6 vs E7 还存在明显参数量差异。

改进方向：设计参数量严格匹配的分层消融，例如固定编码器，只替换更新算子；或使用 factorial ablation 分别开关查询相关性、非负约束和分布族。

### 5.2 Beta-Binomial 的表达能力有限

两参数 Beta-Binomial 能描述过度离散和边界集中，但不擅长表达分离的内部多峰分布。更灵活的 CBSAM 混合模型在当前实验中不稳定，不能说明混合模型永远不可取；只能说明在此数据和训练方案下没有建立优势。

改进方向：研究稳定的混合先验、零膨胀/边界膨胀模型，或用结构化混合而不是直接增加混合分量。

### 5.3 1 小时预测存在明显短板

循环基线在 1 小时更好，集合式证据更新在 3–6 小时更有优势。当前模型没有显式给予“离查询越近的观测”足够强的特殊地位。

改进方向：加入更强的距离到查询时间特征，或融合局部递归状态与全窗口证据聚合。该方向在当前方案中只是合理假设，尚未被实验验证。

### 5.4 点预测能力不足，不能用于所有调度任务

如果下游只关心一个最可能的占用数、短期排班或即时控制，CAMP-NP 的分布优势不一定抵消点误差劣势。应根据决策目标选择模型，而不是默认完整 PMF 总是更好。

### 5.5 zero-shot 不是性能优势

空上下文统一接口是设计优点，但 CAMP-NP 的 zero-shot 先验不优于经验贝叶斯季节先验。不能把“支持 K=0”写成“zero-shot 性能领先”。

### 5.6 容量相关先验没有带来可见收益

E6 与去掉容量相关先验的 E8 几乎相同，差约 0.0005，低于实际解释阈值。这说明容量更适合作为解码支持和归一化信息，而不是必须进入先验头。

### 5.7 数据外推范围有限

实验只有两个中国城市，UrbanEV 覆盖六个月，北京只有两个不连续月份。缺少跨国家、跨运营商、跨季节和更长时间跨度的验证，不能声称广泛泛化。

### 5.8 缺失机制与低覆盖分层仍未解析

UrbanEV 缺失原因未知，模型使用掩码但没有识别缺失是否与占用状态相关。低覆盖站点数量很少，覆盖差异可能成为性能差异的竞争解释。

改进方向：收集缺失原因、加入缺失机制敏感性分析，并扩大低覆盖站点样本。

### 5.9 只输出边际 PMF

模型分别预测 1、3、6 小时的边际分布，并不提供多步联合轨迹分布。因此不能直接回答“未来六小时内是否至少有一次超过 80% 容量”这类需要时间相关性的事件。

### 5.10 评价协议仍有证据等级差异

UrbanEV 是正式盲测；北京的 E6/E7 是冻结盲测，但 E3–E5 是揭盲后扩展。若把这些结果放在同一张表中而不标注证据身份，会夸大外部复现强度。

## 6. 哪些做法可以直接借鉴，哪些不能直接照搬

### 可以直接借鉴

- 将硬约束编码进输出分布或状态更新；
- 用有语义的中间量承载神经网络的灵活性；
- 对缺失信息使用显式掩码并保证其贡献为零；
- 让 zero-shot/few-shot 共享接口，减少协议分叉；
- 在方法设计阶段同步设计可证伪的对照矩阵；
- 区分主指标、诊断指标和探索性分析；
- 对每个结论标明数据集、是否盲测、是否参数匹配和证据边界；
- 明确承认模型在哪些目标上不占优。

### 不应直接照搬

- 不要因为某一物理领域有容量上限，就机械使用 Beta-Binomial；必须先确认目标确实是有界计数，并检查分布是否需要多峰、零膨胀或时间联合结构；
- 不要把“伪计数单调增加”解释成预测均值、方差、校准和准确率也必然单调；
- 不要把 E6 vs E5 的整体收益拆成查询注意力、非负更新或分布族各自的独立贡献；
- 不要把 few-shot 性能优势外推成 zero-shot 优势；
- 不要把概率质量指标的改善写成点预测全面提升；
- 不要把揭盲后扩展结果当作预注册盲测证据；
- 不要因为混合模型更灵活，就默认它一定优于简单分布；稳定性和可识别性同样重要；
- 不要用“严格支持集”替代对缺失机制、时变容量和跨步依赖的建模；
- 不要只用均值指标评价概率预测，也不要只用 CRPS 评价点决策任务。

## 7. 最终评价

CAMP-NP 最有价值的地方，是把“领域约束 + 观测语义 + 概率输出”做成了一个相互一致的结构化接口，并通过对照实验说明：真正有价值的是完整的查询条件化证据更新，而不是单独的容量截断、容量先验或更复杂的混合分布。

它最需要警惕的地方，是结构化设计带来的解释感容易超过实验真正能识别的范围。当前证据支持一个有效的组合方案，不足以证明每个组件都不可替代，也不足以证明它适合所有预测目标。

如果以后要继续创新，最值得沿着三条线推进：

1. 用严格参数匹配的消融拆开查询相关性、非负加性和分布族的作用；
2. 融合短期递归状态与长窗口证据聚合，补足 1 小时预测；
3. 从边际 PMF 扩展到时变容量和多步联合分布，并用更多城市、运营商和季节验证外推性。

# TSF 方案经验速查

> 来源：CAMP-NP、DIET 两份方案复盘。目标是以最小篇幅保留可迁移经验；两方案实验协议与指标口径不同，数值不可横向排名。

## 1. 总结论

两方案最可靠的共同经验是：**先把领域约束与历史观测的语义写成结构化、可验证的更新，再让小网络学习“哪些历史与当前查询相关”**。对未见站点的短历史概率预测，真正稳定的收益主要来自查询条件化的证据选择与更新，而不是更复杂的网络、单独的容量截断或更“精确”的证据表示。

通用流程可压缩为：

```text
合法概率锚点/查询先验
  + 仅用当时可见信息构造的历史证据
  + 面向当前查询的相关性权重
  + 受约束更新与合法支持解码
  -> 完整预测分布
```

## 2. 两个方案分别教会了什么

| 方案 | 核心机制 | 已被实验支持 | 未被支持或不可外推 | 最值得迁移 |
| --- | --- | --- | --- | --- |
| CAMP-NP | 把每条历史占用转成非负“占用/空闲”伪计数，按查询加权后更新 Beta 参数，再以容量为试验数输出 Beta-Binomial PMF | UrbanEV 上相对普通 BB-CNP 的 CRPS 约降 10.8%，相对有界循环对照约降 9.8%；收益主要在 3–6 h 和分布质量 | 1 h 与点预测不占优；zero-shot 先验、容量进入先验头、复杂混合分布均未显示优势；组合收益不能拆成各组件独立贡献 | 用有语义的中间量连接神经网络与概率模型；把非负性、缺失零贡献、顺序不变性和容量支持写进结构；zero/few-shot 共用一条前向路径 |
| DIET | 冻结概率锚点；因果回放历史预测，把离散观测变成概率秩区间；根据查询选择历史证据和有限单调校准映射，在合法容量格点输出 PMF | 相对全源基础模型，主测试/压力测试 dCRPS 约降 6.07%/4.44%；优于查询无关权重、条件先验及全局/局部校准，说明“按查询选择历史概率误差”有价值 | 精确秩区间相对点 PIT 的四组总体差异区间均跨零，最强预设对照门槛未通过；不能声称精确区间有独立性能优势、两者等价、严重缺失鲁棒或跨城市泛化 | 在共同概率坐标上传递不同容量对象的预测误差；冻结锚点以分离基础能力与适应；用因果回放模拟部署；用匹配对照检验新表示是否必要 |

## 3. 可直接复用的设计原则

1. **先定义失败，再设计模型。** 明确基线在什么查询、跨度或分布部位持续失配，以及短历史中什么信号能预示该失配；“泛化不足”不足以约束创新。
2. **硬约束进入参数化。** 有界计数应从分布族或解码上保证 `Y in {0,...,C}`，缺失项贡献严格为零；不要依赖惩罚、截断或事后修补。
3. **历史应有任务语义。** 可把它表示为占用/空闲伪计数、预测残差、PIT/秩区间或状态块，而非默认压成无语义隐状态；表示必须由目标失配决定。
4. **证据选择应面向查询。** 小时、星期、跨度、工况和时间距离会改变历史的相关性；先与查询无关、固定日历匹配、近期窗口和简单衰减比较，再证明神经权重必要。
5. **锚点与适配分离。** 已有可靠预测器且目标数据少、对象频繁变化时，冻结锚点并学习小适配器便于复用和归因；仍须比较全量重训和简单校准。
6. **统一空历史与短历史接口。** 无证据时自然回退查询先验/锚点，有证据时沿同一路径更新；接口一致不等于 zero-shot 性能领先。
7. **优先有限、合法、可解释的修正族。** 小样本下更稳定，也便于检查每条证据如何改变输出；若要增加混合、多峰或零膨胀能力，先证明简单族存在稳定残差。
8. **概率模型服务概率决策。** 需要容量风险、区间或尾部概率时评价完整 PMF；只需要单点调度时必须同时比较 MAE，CRPS 更好不能推出点预测更好。

## 4. 实验与归因规则

- 每个核心主张配一个**同信息、同锚点、同输出族、同训练机会、尽量同参数量**的替代模型；删减模型应独立训练，不能只在完整模型上关模块。
- 对照优先覆盖：更多源数据、强基础架构、无查询权重、条件先验、全局/局部校准、简单时间权重，以及新表示的近似版本。
- 一次只改变一个关键因素；组合模型获胜只能支持组合，不能自动归因到注意力、非负更新、分布族或精确表示中的某一项。
- 评价口径应与训练目标和应用一致；NLL 优化不保证 dCRPS、覆盖率或区间分数同步改善。概率预测至少联合报告适当评分、校准/覆盖、区间宽度和点误差。
- 站点等权可避免高记录量站点主导；空间与时间同时相关时，按空间组和时间块做配对重采样，训练种子不能当作独立样本。
- 预先冻结主指标、强对照、最小有用改进、算力预算和停止条件；置信区间跨零表示“优势未建立”，没有等价界值时也不能写成“已证明等价”。
- 分层结果必须同时给出站点数/样本量。总体改善不能外推到每个跨度、低覆盖层或月份；严重缺失、空历史、跨城市和联合轨迹能力都需单独验证。
- 区分预注册盲测、揭盲后扩展和探索性分析；揭盲后不得换备选、删强对照或加种子追求显著。
- 保存负结果并收窄贡献：DIET 的价值最终是“查询相关概率误差适应”，不是“精确区间必优”；这类结论比维持原命名叙事更可复用。

## 5. 已踩工程坑

| 风险 | 规则 |
| --- | --- |
| 训练/推理反馈尺度不一致，首步正常、后续跨度崩坏 | 训练与推理共用归一化函数，并逐步检查实际反馈值，不只验形状 |
| 错误验证器参与 checkpoint 选择 | 修复后重做选模；旧权重只能诊断，不能作为正式结果 |
| 接近 1 的 CDF 直接相减丢失尾部质量 | 同时保存左尾、右尾和点概率，从数值稳定的一侧计算；不要靠加大概率下限掩盖 |
| 优化器/EM 达到迭代上限 | 用更高上限或替代求解器测量对最终指标的影响；“触顶”既非自动失败，也不可未经验证忽略 |
| 基线异常差导致虚假优势 | 先查尺度、递归反馈、掩码、时间切分和选模链路，再讨论方法优越性 |
| 缺失填零或按未来覆盖率筛站 | 显式掩码，只按预测时已知信息定资格，并报告实际评价人群 |

## 6. 不应照搬

- 不因目标有上限就机械采用 Beta-Binomial；先检查多峰、零/边界膨胀、时变容量和跨步依赖。
- 不把伪计数单调增加误解为均值、方差、校准或准确率必然单调。
- 不把数学上更精确、概率语义更完整或中间量变化更明显直接写成最终预测优势。
- 不以击败弱锚点、单独容量约束或不匹配参数量的消融证明创新。
- 不把 few-shot 优势扩写成 zero-shot 优势，把边际 PMF当作联合轨迹，或把两个月/两城市结果写成广泛泛化。
- 不用复杂模块挽救尚未成立的表示主张；先验证信号确实预示未来误差且超过简单解释。

## 7. 后续最有价值的方向

1. **数量与冲突感知的证据强度：** 区分一条与多条、一致与冲突历史；对照固定强度、按样本数收缩和简单近期加权。
2. **短期状态 + 长窗证据：** 用局部递归状态补足 1 h，用集合式证据服务 3–6 h；须做参数匹配消融。
3. **更灵活但受约束的分布：** 仅在确认简单族留下稳定多峰/边界残差后尝试结构化混合、零膨胀或边界膨胀。
4. **多步联合分布与时变容量：** 支持“未来数小时至少一次拥堵”等事件，不能由边际 PMF直接推得。
5. **真正的稀疏与外部验证：** 预先构造有足够站点的低历史层，并扩展城市、运营商、季节和缺失机制。

最简决策准则：**若新表示没有在匹配对照中把差异传递到最终任务指标，就保留更简单表示；若收益仅来自查询相关证据选择，就把贡献准确地写成查询相关适应。**
